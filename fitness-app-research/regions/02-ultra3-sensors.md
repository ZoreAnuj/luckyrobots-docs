# ultra3-sensors

## Key findings
- Apple Watch Ultra 3 (Sept 2025, watchOS 26, S10 SiP, 64GB storage) carries the same core sensor suite as Ultra 2 — third-generation optical heart (PPG) sensor, electrical heart sensor (ECG), blood oxygen sensor, wrist temperature sensor, water temperature sensor, depth gauge (dive-ready to 40m), compass, always-on barometric altimeter, high-g accelerometer, high-dynamic-range gyroscope, ambient light sensor — reviewers confirm zero sensor hardware changes vs Ultra 2, so all Ultra 2 developer APIs apply unchanged.
- What IS new on Ultra 3 vs Ultra 2: satellite communications (Emergency SOS, Messages via satellite, Find My location via Globalstar LEO satellites, free for 2 years), 5G cellular, brighter wide-angle LTPO3 OLED (3000 nits vs 2000, larger active area, 1Hz always-on refresh with ticking seconds hand), battery 42h normal / 72h Low Power Mode (vs 36h/72h), and 0-80% charge in 45 min.
- GPS is precision dual-frequency (L1 + L5) with GPS, GLONASS, Galileo, BeiDou, and QZSS constellations. Critically for the app: there is NO raw GNSS measurement API on Apple platforms — the dual-frequency benefit arrives automatically as more accurate CLLocation fixes via CoreLocation, which works fine in third-party watchOS workout apps for Strava-like route recording (pair with HKWorkoutRouteBuilder to persist routes into HealthKit).
- Nearly every processed health metric is third-party readable via HealthKit with user permission: heart rate, resting HR, HRV (SDNN only), heart rate recovery (1-min), VO2max, oxygenSaturation, ECG waveforms (HKElectrocardiogram incl. 512Hz voltage data + classification), nightly wrist temperature (appleSleepingWristTemperature), sleep stages (core/deep/REM/awake), respiratory rate, breathing disturbances, AFib burden, running form metrics (power, stride length, vertical oscillation, ground contact time), cycling power/cadence, workout effort scores, and daily activity (active energy, exercise minutes, stand hours, steps).
- What is LOCKED away from third parties: raw PPG optical signal, continuous/real-time skin temperature (only the nightly sleeping aggregate is exposed), the ambient light sensor, triggering an on-demand ECG or Blood Oxygen reading programmatically (you can only read samples the system records), Apple's computed Sleep Score and Training Load numbers (no HealthKit identifiers — only the underlying inputs are readable), the Vitals app's 'typical range/outlier' status, and all satellite messaging features (no watchOS satellite API at all).
- The depth gauge / water temperature during submersion require CoreMotion's CMWaterSubmersionManager, gated behind entitlements: com.apple.developer.submerged-shallow-depth-and-pressure (publicly requestable) vs the full 40m com.apple.developer.submerged-depth-and-pressure (restricted, Apple-approval only, historically reserved for Oceanic+ partners). Restricted entitlements are NOT grantable on a free provisioning personal team, so a sideloaded personal app effectively cannot use live submersion data — but HealthKit still exposes recorded waterTemperature and underwaterDepth samples from Apple's own dive/swim workouts.
- High-rate motion data IS available to third parties: CMBatchedSensorManager (watchOS 10+, Series 8/Ultra and later) delivers 800Hz accelerometer and 200Hz device-motion batches, but ONLY while an active HKWorkoutSession is running — ideal for rep counting or swing/stroke detection. Standard CMMotionManager caps at ~100Hz anytime. CMAltimeter exposes both relative altitude/pressure and absolute altitude (watchOS 8+), so elevation-gain charts for hikes are fully buildable.
- watchOS 26 added Hypertension Notifications (passive 30-day PPG blood-vessel analysis, FDA-cleared, works on Ultra 2 and later) and Sleep Score. iOS 26.2 added a HealthKit API to read hypertension events (new hypertension event category type), meaning the app can surface Apple's hypertension alerts; Sleep Score itself remains Apple-private, but its inputs (duration, stages, wake events, bedtime consistency) are all readable so a clone score is computable.
- Blood Oxygen on US-sold Ultra 3 units works via the redesigned post-ITC-ban pipeline (re-enabled Aug 14, 2025): the sensor measures on the watch but analysis/display happens on the paired iPhone's Health app. The resulting oxygenSaturation samples still land in HealthKit and are readable by third-party apps either way, so the app's recovery/sleep features can rely on SpO2 data.
- During workouts, third-party watch apps get live streamed metrics via HKLiveWorkoutBuilder/HKLiveWorkoutDataSource (heart rate roughly every 1-5 seconds, active calories, distance, pace, running power live on watchOS 10+), and HKWorkoutSession grants background runtime + sensor priority — this is the exact same pipeline Apple's own Workout app uses, so a personal app loses essentially nothing for workout tracking. Double Tap / wrist-flick gestures are exposed to apps only via SwiftUI's handGestureShortcut(.primaryAction) modifier (watchOS 11+).

## Specifics
- Full Ultra 3 sensor list: third-gen optical heart sensor, electrical heart sensor (ECG), blood oxygen sensor (red/IR LEDs), wrist temperature sensor, water temperature sensor, depth gauge (to 40m, EN13319 dive accessory rating, WR100), compass, always-on altimeter, high-g accelerometer (256 g-force class, powers fall/crash detection), high-dynamic-range gyroscope, ambient light sensor
- Chip: Apple S10 SiP, 64-bit dual-core, 4-core Neural Engine; 64GB storage; Wi-Fi 4 (802.11n), Bluetooth 5.3, 5G cellular, NFC/Apple Pay, GymKit
- GNSS: precision dual-frequency GPS (L1+L5) + GLONASS, Galileo, BeiDou, QZSS; no raw-GNSS API — consume via CoreLocation CLLocationManager (kCLLocationAccuracyBest) inside an HKWorkoutSession
- Battery: up to 42h normal, 72h Low Power Mode, 0-80% in ~45 min fast charge; display 3000-nit wide-angle LTPO3 OLED, 1Hz AOD
- Satellite: Globalstar LEO; Emergency SOS via satellite, Messages via satellite (iMessage+SMS, E2E encrypted), Find My manual location update every 15 min; free 2 years; zero developer API
- HealthKit identifiers usable by the app: heartRate, restingHeartRate, walkingHeartRateAverage, heartRateVariabilitySDNN, heartRateRecoveryOneMinute, vo2Max, oxygenSaturation, respiratoryRate, appleSleepingWristTemperature, appleSleepingBreathingDisturbances (iOS 18+), atrialFibrillationBurden, bodyTemperature, waterTemperature, underwaterDepth, activeEnergyBurned, basalEnergyBurned, appleExerciseTime, appleStandTime, stepCount, distanceWalkingRunning, flightsClimbed, runningPower, runningSpeed, runningStrideLength, runningVerticalOscillation, runningGroundContactTime, cyclingPower, cyclingCadence, cyclingSpeed, workoutEffortScore, estimatedWorkoutEffortScore (both iOS 18+, read/write)
- HealthKit category/sample types: HKCategoryValueSleepAnalysis with stages asleepCore/asleepDeep/asleepREM/awake; HKElectrocardiogram (classification + ~512Hz voltageMeasurements, read-only, cannot trigger); irregularHeartRhythmEvent, lowHeartRateEvent, highHeartRateEvent, lowCardioFitnessEvent; new hypertension event category type (reported as HKCategoryTypeIdentifierHypertensionEvent, iOS 26.2+)
- Workout stack: HKWorkoutSession + HKLiveWorkoutBuilder + HKLiveWorkoutDataSource for live HR/calories/pace on-watch; HKWorkoutRouteBuilder + CLLocationManager for GPS routes (read back via HKWorkoutRoute for map rendering); WorkoutKit (iOS 17+) for scheduling structured/interval workouts into Apple's Workout app
- CoreMotion: CMMotionManager (~100Hz accel/gyro/deviceMotion), CMBatchedSensorManager (800Hz accelerometer, 200Hz device motion; Series 8/Ultra+; requires active HKWorkoutSession), CMAltimeter (relative altitude + pressure; CMAbsoluteAltitudeData watchOS 8+), CMPedometer, CMWaterSubmersionManager (entitlement-gated: com.apple.developer.submerged-shallow-depth-and-pressure = public-requestable shallow access; com.apple.developer.submerged-depth-and-pressure = restricted full 40m access)
- NOT exposed to third parties: raw PPG waveform, real-time skin temperature, ambient light readings, programmatic trigger of ECG/SpO2 spot measurements, Apple Sleep Score value, Apple Training Load value, Vitals outlier status, satellite messaging, double-tap gesture as raw event (only handGestureShortcut(.primaryAction) SwiftUI modifier, watchOS 11+)
- US Blood Oxygen pipeline (post Aug 14, 2025 / units with part numbers ending LW/A): measurement on watch, computation+display on paired iPhone Health app; oxygenSaturation samples still written to HealthKit and third-party readable
- Hypertension notifications: optical-heart-sensor algorithm analyzing blood vessel response passively over 30-day windows, FDA-cleared, Series 9+/Ultra 2+ on watchOS 26 — Ultra 3 supported
- Sleep Score (watchOS 26): computed from duration, bedtime consistency, awakenings, stage distribution — score itself not in HealthKit; all inputs are, enabling a custom recomputed score
- watchOS heart rate delivery cadence: ~1 sample per ~5s continuously in workout sessions via HealthKit statistics updates (near-real-time for a live workout UI); background (non-workout) HR sampled by system every few minutes only
- HealthKit capability works with a free Apple Developer personal team (sideload via Xcode, 7-day profile expiry re-sign cycle); restricted entitlements (full submersion depth) are not available to personal teams

## Recommendations
- Build the workout engine on HKWorkoutSession + HKLiveWorkoutBuilder (live HR, calories, pace) and HKWorkoutRouteBuilder + CoreLocation for Strava-like GPS maps — the Ultra 3's L1+L5 GPS accuracy flows in automatically through standard CLLocation; render stored HKWorkoutRoute polylines in MapKit on the iPhone side.
- Design the recovery/sleep pillar around what HealthKit actually exposes: sleep stages, nightly wrist temperature delta, HRV SDNN, resting HR, respiratory rate, SpO2, and 1-min heart rate recovery — and compute your own sleep score / readiness score, since Apple's Sleep Score and Training Load numbers are not readable.
- Use workoutEffortScore (write it from your app after workouts) and estimatedWorkoutEffortScore as the basis for the RPG XP system — effort scores are first-class read/write HealthKit types and integrate with Apple's own Training Load display.
- Skip live submersion/depth features: CMWaterSubmersionManager needs entitlements a free-provisioning personal team cannot get; if swim/dive data matters, read the waterTemperature and underwaterDepth samples Apple's own workouts write to HealthKit instead.
- For rep counting or form analysis features, use CMBatchedSensorManager (800Hz accel / 200Hz device motion) inside the active workout session — no special entitlement needed on Ultra-class hardware.
- Do not plan any features on satellite messaging, raw PPG, on-demand ECG/SpO2 triggering, or continuous skin temperature — all Apple-locked; treat ECG and SpO2 as passive read-only historical data.
- Request HealthKit read authorization up front for the full identifier list in specifics (batch it into one permission sheet), and enable HealthKit background delivery on the iPhone app so nightly sleep/recovery data refreshes without opening the app.
- Add the handGestureShortcut(.primaryAction) modifier to the watch app's primary workout button so Double Tap / wrist flick works, matching first-party app feel.
